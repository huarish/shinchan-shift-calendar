# 我的排班 · 小新陪你

适配 iPhone 的随身排班网页，包含 2026 年 9、10、11 月排班。用户已确认公开发布。

## 使用

在本仓库 Settings → Pages 中查看网站链接。iPhone 用 Safari 打开网址，点击分享 → 添加到主屏幕。首次在线加载完成后，可离线查看已缓存的排班。

支持月份和人员切换、整月日历、未来 3/7 天跨月查询、后续班次、当天全员与同日多岗位显示。小新与小白插画配轻量动画，并尊重系统减少动态效果设置。

## 数据

9 月保留原项目记录；10、11 月来自用户提供的 Word 逐日表格，原始 Word 未上传。共 91 天、577 条岗位记录。空白表示原表未列排班，不代表已确认休假。公开网站和仓库可查看其中的姓名和排班。

## 发布

GitHub Pages 使用 main 分支根目录部署。更新网页或 schedule.json 后提交到 main，GitHub 自动重新发布。修改离线资源时同时更新 sw.js 缓存版本。以后增加月份还需修改 app.js 中的数据截止日期提示。

## 验证

核心测试 8 项通过；10、11 月 427 个日期岗位单元格（含空白）与 Word 逐项一致。Chromium 在 320、375、390、430、900 像素宽度下无横向溢出；跨月、多岗位、离线刷新、人员记忆和减少动态效果测试通过。尚未进行真实 iPhone Safari 测试。

## 本地运行

使用 HTTP 静态服务器打开，例如 python -m http.server 8765 --bind 127.0.0.1。不能直接双击 HTML。
