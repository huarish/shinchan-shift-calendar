# 我的排班 · 小新陪你

私人排班日历，包含2026年9、10、11月。支持人员切换、跨月查询、同日多个岗位、整月日历、小新动画及离线 PWA。

## 隐私和发布状态

本仓库仅用于私有保存。未启用 GitHub Pages，不允许公开发布排班姓名和日期。私有仓库并不自动保证由它部署的网页也是私有。手机在线访问需要提供真正的登录访问控制，并保护网页、JSON和图片等所有资源。

## 本地使用

使用静态 HTTP 服务器打开项目，例如 `python -m http.server 8765 --bind 127.0.0.1`。不能直接双击 HTML。首次联网加载完成后，浏览器可离线查看已缓存排班。不要在公共设备上保存个人排班缓存。

## 数据

9月保留原项目记录；10、11月来自用户提供的Word逐日表格。原Word未上传。空白表示原表未列班，不代表确定休假。共91天、577条岗位记录。

## 验证

核心测试8项通过；10、11月427个日期岗位单元格（含空白）与Word逐项一致；Chromium移动宽度320、375、390、430及桌面900像素无横向溢出；跨月、同日多岗位、离线、人员记忆和减少动态测试通过。尚未进行真实iPhone Safari验证。
